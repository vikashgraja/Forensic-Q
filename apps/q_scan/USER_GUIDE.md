# `q_scan` — Investigator & Auditor User Guide

## 1. Investigative Workflow
1. **Target Drive Selection:** Select the custodian drive or mounted forensic image (e.g. `E:\Custodian_Evidence`).
2. **Execute Triage Scan:** Q-Scan searches all office documents, text files, and archives for target entities, PAN numbers, and keywords.
3. **Review Hits Ledger:** Filter by keyword matches and file modification dates to identify tampered or newly created evidence files.
4. **Locate & Export:** Copy source evidence paths and file hashes directly to the case dossier.
