# `q_chat` — Investigator & Auditor User Guide

## 1. Investigative Workflow
1. **Chat Channel Import:** Upload chat archive exports from Microsoft Teams, Slack, or WhatsApp.
2. **Search Conversations:** Filter by custodian handles, keyword terms, or suspicious time windows.
3. **Thread Context View:** Inspect the messages preceding and succeeding a flagged transfer or sensitive invoice request.
4. **Export Chat Evidence:** Generate formatted PDF transcripts with verified message timestamps for case filings.
