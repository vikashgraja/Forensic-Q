# `q_verify` — Investigator & Auditor User Guide

## 1. Investigative Workflow
1. **Upload Documents:** Submit questionable invoices, agreements, or minutes.
2. **Review Authenticity Gauge:** Scrutinize documents with an authenticity score `< 50`.
3. **Analyze Discrepancies:** Detect backdated contracts where the PDF metadata timestamp is months after the purported agreement date.
4. **Export Certificate:** Generate an automated digital forensics authenticity report.
