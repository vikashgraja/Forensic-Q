# `q_mail` — Investigator & Auditor User Guide

## 1. Investigative Workflow
1. **PST Import:** Point the extractor to custodian PST archives or EML export folders.
2. **Search Keyword Hits:** Query sensitive keywords (e.g. `kickback`, `cash`, `offshore`, `invoice adjust`, `destroy`).
3. **Thread Reconstruction:** Group emails by thread ID to reconstruct full chronological discussions between counterparties.
4. **Attachment Extraction:** Inspect suspicious attachments, hashes, and matching financial invoices.
